## 1. Rational preimages by 2h-bit recurrence (verified)

T is unitriangular: bit i of Tx is x_i XOR a function of strictly lower bits (with zero padding at negative indices), so by induction on the updates bit_i(T^h x) = x_i XOR H_h(x_{i-2h..i-1}) with H_h computable by h local steps. Hence digits solve successively and T^{-h}(y) exists uniquely in Z_2. For i >= B = bitlen(y) the output digit is 0, so x_i = H_h of the preceding 2h-bit window: one autonomous map on 2^(2h) states. Among 2^(2h)+1 consecutive windows two repeat, giving onset a <= B+2^(2h) and period p <= 2^(2h) (nonsharp, sufficient); h = 0 gives x = y with zero tail of period 1. Period preservation holds since T^t output at i >= a+2t has input cone inside the periodic tail (left-expansion 2 per step). The finite recursion is proved before any description is read off, so no truncation is mistaken for a certificate.
