# Problem 1: the infinite moving fringe has pro-2 recurrence

## Status

Rigorous structural refinement of the moving-fringe stopping fence. This does **not** solve Problem 1.

## Setup

Let `R` be the right endpoint of the original finite row and

    a_j(t) = (T^t r)_{R+t-j},  j >= 0.

For each finite prefix `A_J(t)=(a_0(t),...,a_J(t))`, the preceding note proved that the Rule-30 update is a triangular XOR permutation and therefore has power-of-two order.

Write `F_J` for the update on the first `J+1` coordinates and

    ord(F_J)=2^m_J.

Because the prefix maps are compatible under truncation, `ord(F_J)` divides `ord(F_(J+1))`; equivalently the exponents `m_J` may be taken nondecreasing.

## Lemma: simultaneous return of every prescribed finite depth

For every `J`,

    F^(2^m_J)(x)_0..J = x_0..J

for **every** infinite moving-fringe state `x`, not merely for the particular orbit generated by the original row.

Thus the times

    N_J = 2^m_J

are universal return times for depth `J`. As `J` increases, these are nested dyadic return scales.

In the product topology on `{0,1}^N`, this means that a sequence of powers of two sends the entire infinite fringe map back to the identity:

    F^(N_J) -> id

coordinatewise (after passing to strictly increasing depths/times when necessary; if the orders stabilize, some fixed power already acts as the identity on every finite prefix and hence on the whole fringe).

Therefore every moving-fringe orbit is recurrent in a particularly strong way: arbitrarily deep finite windows return **simultaneously** at dyadic times.

## Pro-2 interpretation

The infinite moving-fringe dynamics is the inverse limit of its finite triangular 2-group actions. In this precise sense it is a pro-2 action.

A useful consequence is that every continuous finite-valued observable of the infinite fringe factors through some finite prefix, because a continuous map from the compact product space `{0,1}^N` to a finite discrete set is uniformly locally constant. Hence every such observable returns at a power-of-two time.

More generally, any finite-state factor determined continuously from the instantaneous moving fringe can have only dyadic cycle lengths.

## Consequence for the proposed FULL-phase route

The previous note suggested looking for an anchored FULL/nonreset phase condition incompatible with dyadic recurrence. This note shows that the obstruction must be stronger than merely choosing a larger but still finite fringe window.

For every finite collection of anchored moving-edge bits, there is one dyadic time that restores **all of them at once**. Therefore no argument of the form

    inspect sufficiently many (but finitely many) moving-edge bits,
    assign a finite phase/resource state,
    prove that this state cannot recur

can succeed if that state is determined only by the instantaneous moving fringe. The pro-2 recurrence forces recurrence of that entire finite observation.

A successful non-reuse theorem must therefore use at least one ingredient not represented by a continuous finite-valued function of the instantaneous moving fringe, for example:

1. unbounded-depth information with a genuinely uniform condition that cannot be reduced to any finite prefix;
2. history/source identity that is not recoverable from the instantaneous fringe alone; or
3. coupling to the core/global shadow/physical-delay process, with an obstruction that has an odd or otherwise non-dyadic component.

This strengthens the stopping fence from `problem1_moving_fringe_periods_are_dyadic.md`: not only does each fixed prefix recur dyadically, but arbitrarily deep finite prefixes can be synchronized by a single nested sequence of dyadic returns.
