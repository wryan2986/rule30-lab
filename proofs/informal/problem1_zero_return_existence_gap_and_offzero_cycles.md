# Problem 1: zero-return existence gap and off-zero cycles

## Correction to runs 72–77

The no-merger and zero-return-graph acyclicity arguments are valid for **zero-return vertices and edges that actually exist**, but they do not prove that every singular integration is followed by another zero return.

This distinction matters.  A first-return edge from a zero target is defined only if the deterministic off-zero inverse connector eventually reaches another zero column (equivalently, by run 77, another diagonal pair `a=b`).  Finiteness of the ambient state space does not force such a hit: the connector can instead enter a periodic orbit consisting entirely of nonzero, off-diagonal pairs.

Therefore the run-72 statement that finiteness plus zero-return-graph acyclicity excludes all infinite reverse branches was too strong.  An infinite branch need not repeat a **zero-return vertex**; it may eventually cycle entirely between zero columns and hence create no cycle in the compressed zero-return graph.

The same caveat propagates to the strongest wording in run 74.  The inherited-subgraph/portal picture is valid conditional on the relevant portal connectors returning, but the assertion that every old leaf necessarily has a finite full-period binary tree attached is not yet proved at all dyadic depths.

## Exact injectivity of the off-zero pair map

This gap can be formulated sharply using the deterministic inverse pair map

`T(a,b) = (y,a)`,

where for `a != 0`, `y` is the unique solution of

`b = S y xor (a or y)`.

On the domain `a != 0`, `T` is injective.  Indeed, from an output `(y,a)` one recovers `a` directly as the second component, and then recovers the unique input `b` from

`b = S y xor (a or y)`.

Consequently, if a connector fails to hit the diagonal/zero-return set, finite-state dynamics imply that it eventually lies on a genuine periodic orbit of the off-zero map.  Injectivity rules out transient merging into a previously visited cycle along the same all-off-zero domain: once a state repeats, the intervening segment is periodic.

Thus the remaining global alternative for each portal is exact:

1. it reaches the diagonal `a=b`, hence produces the next zero return; or
2. it belongs to / reaches an off-diagonal periodic orbit and never returns to zero.

Ruling out alternative (2), at least for the portal states generated by dyadic leaf doubling, is now a necessary theorem before the unconditional all-depth tree recursion can be used.

## Stronger p=32 computational lower bound

I independently reimplemented the established bit recurrence

`y_{i+1} = b_i xor y_i` if `a_i=0`, and `y_{i+1}=not b_i` if `a_i=1`,

using packed 32-bit states, and initialized the first canonical period-16 leaf

`l = 0000010101000101`

at its doubled period-32 portal `ll`, choosing one of the two phase-equivalent derivative integrations.  The resulting exact traversal did not hit `a=b` within **100,000,000** predecessor iterations.  This strengthens run 75's 10,000,000-step lower bound by one order of magnitude (subject to the same bit-orientation convention; reversal/rotation does not change the necklace-level return question).

This makes the existence gap operationally important rather than merely formal: the first p=32 portal has not yet been shown computationally to return at all.

## Revised target

Before spending effort on a complete `G_32` census, prioritize one of:

- prove that the dyadic portal states cannot lie on an off-diagonal periodic orbit;
- derive an invariant distinguishing portal states from all off-diagonal cycles;
- or use cycle detection / an accelerated multi-step representation to decide the first p=32 portal exactly.

The compressed zero-return tree theorems remain useful once return existence is established, but return existence is now the principal unresolved logical gap.
