# Problem 1: reachable zero-return graph acyclicity theorem

## Purpose

Run 71 proved that the simple zero-column first-return graph modulo cyclic rotation has indegree at most one. The remaining graph-theoretic obstruction was stated as cycles / nontermination. For the component actually generated by reverse search from the terminal root `(0,0)`, the no-merger theorem already rules out every nontrivial cycle once the special root is handled separately.

## Setup

Use the same dynamics and orientation as the no-merger theorem:

\[
F(a,b)=(b,\;Sa\oplus(b\lor a)),
\]

with zero states `Z(w)=(0,w)`. A simple directed edge `[Z(w)] -> [Z(z)]` means one nontrivial admissible reverse integration at `[Z(w)]`, followed by unique reverse propagation, first reaches `[Z(z)]`; connector interiors contain no zero state. Let `G_p^0` denote the simple subgraph reachable from the terminal root

\[
r=[Z(0)]=[(0,0)].
\]

Run 71 proved that every vertex in the simple zero-return graph has indegree at most one.

## Lemma: the terminal root has no incoming nontrivial edge

There is no simple first-return edge `[A] -> r` from a distinct zero-state necklace `[A]`.

### Proof

Suppose such an edge existed and reverse its connector. This gives a positive-length forward orbit segment beginning at a representative of `r=(0,0)` and ending at a representative of `A`.

But

\[
F(0,0)=(0,0),
\]

so the forward orbit of `(0,0)` is stationary. It can never reach a distinct zero state. Contradiction. QED.

(The algebraic zero integration that stays at `(0,0)` is the trivial stationary self-preimage and is not a nontrivial zero-to-zero first-return connector.)

## Theorem

**Reachable acyclicity theorem.** The simple zero-column first-return graph reachable from `r=[(0,0)]` contains no directed cycle.

This holds at every period and does not require a finite-state census.

### Proof

Assume a directed cycle `C` is reachable from `r`.

First, `r` cannot lie on a nontrivial directed cycle: any cycle edge entering `r` would contradict the root lemma.

Hence `r` is outside `C`. Choose a shortest directed path from `r` to any vertex of `C`, and let `v` be the first cycle vertex on this path. Its predecessor `u` on the path lies outside `C`, so `u -> v` is one incoming simple edge. Since `v` lies on a directed cycle, its preceding cycle vertex `c` also gives an incoming edge `c -> v`. The vertices `u` and `c` are distinct because `u` is outside `C` and `c` is inside it.

Thus `v` has indegree at least two, contradicting run 71's no-merger theorem. Therefore no reachable directed cycle exists. QED.

## Consequences

1. **Cycles are removed as a separate obstruction.** Every zero-return state reached by reverse search from the terminal pair lies in an acyclic simple graph.

2. Combining reachable acyclicity with no-merger gives a rooted tree structure for the entire reachable zero-return component, whether or not that component has yet been explicitly enumerated. The only caveat for termination is infinitude: at fixed period the state space is finite, so this caveat also disappears.

3. At fixed period `p`, there are only finitely many zero-state necklaces (at most `2^p`). Therefore an infinite reverse zero-return path would repeat a vertex, creating a directed cycle. Since cycles are impossible, every reverse branch from the terminal root reaches a leaf after finitely many zero returns.

4. Consequently, for every fixed period, the terminal reverse basin modulo rotation is a **finite rooted tree**. There are no mergers, no cycles, and no infinite branches.

5. The remaining structural/counting problem is therefore solely local: classify reachable even-parity zero targets whose two derivative integrations phase-collapse versus produce two distinct child necklaces, and classify which leaves satisfy the legal full-period/odd-parity initial-state condition.

6. Whenever all leaves in the relevant component are legal terminating initial necklaces, the exact tree identity applies unconditionally:

\[
L=B+1,
\]

where `B` is the number of genuine binary branching vertices. More generally, the graph-theoretic leaf count still satisfies the corresponding rooted-tree identity; legality is a separate boundary classification.

## Research significance

Runs 64-71 progressively reduced the reverse dynamics from arbitrary predecessor trees to zero-column first returns, then excluded mergers. This theorem closes the remaining global graph-topology gap. At any fixed period, the terminal reverse basin cannot exhibit hidden recurrent/nonterminating zero-return dynamics. Future work should stop searching for a monotone quantity to exclude cycles; it is unnecessary. The useful target is now the arithmetic/combinatorial characterization and count of genuine branching zero targets and legal leaves, especially under `p -> 2p`.
