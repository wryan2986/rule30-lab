# Astra automation handoff — run 82

## Main result: rho is natural under rotations and repetition

Starting from run 81's boundary-to-diagonal bijection `rho_p`, this run proves two exact structural laws.

1. Rotation equivariance:

`rho_p(S^k x) = S^k rho_p(x)`.

Hence `rho_p` descends to a bijection on nonzero necklaces.

2. Repetition compatibility. If `q | p`, `m=p/q`, and `R_m(u)=u^m`, then

`rho_p(R_m(u)) = R_m(rho_q(u))`.

In fact the entire period-p connector from `(R_m(u),0)` is exactly the repeated period-q connector, with identical connector length. For doubling:

`rho_{2p}(uu)=rho_p(u)rho_p(u)`.

The proof uses the fact that shift, OR, XOR, and the unique off-zero predecessor all commute with repetition.

## Strong corollary: exact rotational period is preserved

Because `rho_p` is both rotation-equivariant and injective, the rotational stabilizer of `x` equals the rotational stabilizer of `rho_p(x)`. Therefore

`per(rho_p(x)) = per(x)`.

So the endpoint bijection is block-diagonal by exact rotational period. At dyadic ambient periods, every proper-period sector is recursively inherited from lower periods; genuinely new behavior of `rho_p` is confined to the primitive/full-period sector.
